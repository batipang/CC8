# MiniMax 识别语言提示

后台0.16.12／原签名助手0.9.73（code110）已部署，增加“设置 → 识别语言”。当前运行见[部署记录](CURRENT_DEPLOYMENT.md)。

默认“自动／中英混合”完全保留原请求，不发送语言提示；另可明确选择中文`zh`或英文`en`。自动适合大黄蜂、Bumblebee、Dot等中英混合称呼；语言提示不是翻译、热词、文本替换或准确率保证。识别后的原文仍按原流程显示，纠错继续采用[可撤回草稿](SPEECH_CORRECTION.md)。

依据MiniMax官方SDK源码[`be73bb1`的Speech模块](https://github.com/MiniMax-AI/cli/blob/be73bb1df2f7d8e517559ea82c9b2cc51d380aff/src/sdk/speech/index.ts)：语言通过HTTP的`language`请求头传入，表单同名字段会被忽略。当前候选只允许auto／zh／en，auto省略请求头；仍使用同一官方HTTPS端点、现有密钥和模型、有界内存WAV、禁止重定向及原取消／网络预算，不保存录音或增加自动重试。未找到当前ASR接口的可靠热词参数说明，不发送猜测的hotwords／prompt字段。

先暂停语音并等待识别、回答、播报、校准、取景、文字任务及队列空闲，才能明确应用。修改不停止正在进行的任务，不开启麦克风，不发模型请求。仅当前Mac服务内存有效，换线保留选择；服务重启恢复自动，原配置文件不变。恢复自动先选中默认项，仍需点应用。取消不提交。

语言与语速／自然插话共享修订号，旧页面或重复应用不能覆盖较新的设置；USB／Wi-Fi变化、Home关闭旧页，不从另一条线路自动补发。状态只来自当前认证连接的真实后台回执；旧后台和非MiniMax识别保持能力不可用，原有语速功能仍兼容。

软件检查覆盖真实设备事件准入、所有管线忙碌保护、修订、恢复自动、协议字段、实际WAV与HTTP请求头、取消与旧线路Java回调。固定公开音频的真实服务核对另留记录；不以模拟HTTP证明云端效果，也不以单个样本宣称真人／电视／远场准确率提高。环境预设、用户词表和完整P1-07仍开放，72小时最后进行。

真实云端核对（2026-11-09）：同一仓库固定合成参考WAV分别以auto与zh请求各一次，均获得完整非空回执，31字结果一致，耗时0.843／0.919秒。没有设备开麦或播放，也没有修改正在运行的配置；只证明这两个请求路径可用，不构成语言提示提高准确率的证据。

正式原签名界面六项检查150.919秒通过：初始自动、取消不应用、实际中文／英文应用、恢复自动及关闭；独立前台／原后台核对保持同一实例、原配置和私有存储，零新增正式模型请求。自动模式已恢复，详见[实际部署](CURRENT_DEPLOYMENT.md#01612code110-识别语言提示)。
