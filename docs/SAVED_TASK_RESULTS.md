# P1-02：显式保存已结束任务的结果摘录

后台候选 0.14.2 / 助手 APK 0.9.0 code 35 / 协议 2。日常任务仍只在 RAM；本功能不自动保存历史，不上传已保存记录、不恢复执行任务，也不启动麦克风或相机。当前运行助手未替换。

## 设备端入口

- 任务详情中，已完成/失败/已停止的任务显示“保存结果”。确认框说明保存范围后才发请求；仍在执行或已不在当前任务页的任务拒绝保存。
- 任务页首行“已保存结果 · 重启后可查”；本次服务暂无任务时也有“已保存结果”按钮。打开时只列标题、结束状态和保存时间，选择后才读取具体摘录。
- 记录详情显示历史快照、步骤和结果摘录，支持复制、单条删除。删除只作用于这份本机记录，不撤销工具操作，不删除结果文件、桌面聊天或当前任务卡。

只保存后台真实任务回执的白名单字段：本地 task ID、标题（80 字符）、结束状态、最多五个已有步骤 ID/标题/状态、结果摘录（1600 字符）、原开始和保存时间。客户端只能指定当前 task ID，不能提交自己的“成功”状态、结果或步骤。它不是完整聊天、完整审计日志、完整输出文件备份或原 Dot 线程恢复；未保存的 RAM 任务重启后仍消失。历史快照不代表现在仍在执行，也不伪造待审批或恢复按钮。

## 存储和并发

若后台曾把任务标为“执行结果待核对”，新保存的回执会在重启后保留这个状态，并提醒在 Mac 核对原任务后再决定是否重新交办。普通失败和取消仍显示原状态。旧回执缺少这一记录时沿用原有显示。

已完成任务的详情可另外显示“结果播报部分确认”“结果已确认播完”或“结果摘录已确认播完”。判定依据是设备连续收到的播完回执与本次结果文本能否对齐。中途缺失回执时，续读从首句未确认的内容开始，即使后面有相同句子已经确认，也不会跳过前面的缺口。续读可以补齐实时任务的播报记录，明确保存的历史快照只保留保存当时的记录。无法对齐或没有确认时不显示播完步骤。播报状态不改变原任务的执行结果。

文件仅在首次明确保存时创建，位于实际运行目录的 device-access/private/voice-runtime/saved-task-results.json。目录必须 owner-private（0700），JSON 与锁文件 0600；拒绝公开目录/文件、链接、硬链接、重复字段、未知/损坏 schema、超长或非法条目，不自动 chmod 外部目录或以空库覆盖损坏文件。懒读取使损坏的可选保存库不会阻止正常启动/握手。

最多 32 条 / 512 KiB，容量满时要求明确删除，不自动淘汰已选内容。重复保存相同 task ID 和相同快照返回原记录，内容不一致则拒绝覆盖。不同实例用有两秒竞争上限的文件锁串行写入；临时文件 flush/fsync 后原子替换并同步目录，替换前失败保留原文件且清理临时文件。

只有一个存储工作槽，文件锁等待和数据同步在后台线程执行。保存或删除在原子替换前重新核对原认证线路和主人会话；切线或切换到访客后，未提交的操作会清掉临时文件，已经提交的结果仍可刷新核对。存储完成先释放工作槽再发布回执，旧 worker 收尾不能清掉由回执触发的新刷新 worker。断连后不将结果回包发到新的连接。响应丢失或超时显示“未确认，请刷新”，不会自动重试、重跑任务或把持久化失败改写成工具执行失败。

所有查询沿原认证通道，metadata 列表和单条详情均有容量边界，最坏 Unicode 内容仍小于 64 KiB 帧限制。客户端用随机请求 ID 丢弃旧回包，退出前台清理等待 UI。握手广告可选功能；旧后台未确认能力时，入口立即说明，不一直等待。旧 0.14.0 后台实际 dot_chat_state 也可确认摘要接续能力。

## 数据边界与恢复

不保存录音、照片、凭据、任意 provider 异常、采集代次或完整聊天。只在本机按明确选择保存任务标题/结果，重启查看不把记录送给模型。复制是用户点击的本地剪贴板操作。记录随运行目录，不自动跨工作区搬迁；[升级准备工具](UPGRADE_PREPARATION.md) 明确不备份此内容，迁移应在停服后另行处理私有存储。损坏文件保持原样，先私下保留副本再人工核对，不能通过自动重置隐藏数据丢失。

## 软件验证和未完成范围

十五项新增回归实际使用私有临时文件和真实线程：保存/重开/读/删、不默认建库、幂等与禁止改写、未结束和伪造字段拒绝、容量/最坏 Unicode 帧预算、损坏/权限/链接/原子替换失败、八个独立实例竞争写、文件锁超时、断连后的确认语义、删除立即刷新与旧 worker 收尾竞态，以及损坏可选库不阻止握手。所有数据为合成任务，没有读真实私人任务库或接触设备。

P1-02 仍保持开放：本批完成的是明确选择的终态结果快照。完整文件/来源入口、真实桌面授权交接及实机重启/查看/删除体验尚未完成验收；没有将本批软件测试当作上述验收。其他 P0 真人/物理验收保持原状态。测试和构建证据见 [VALIDATION](VALIDATION.md)。
