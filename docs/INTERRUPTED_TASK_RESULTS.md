# 执行中断后的结果提示

## 新客户端行为

0.9.9/code44源码候选在连接丢失前检查当前真实任务快照：若仍有running任务，留下一个RAM-only的“上次执行 · 结果待核对”提示，再按原规则清空旧任务/提醒数组。不保存旧标题、正文、ID或聊天，不生成假的失败/完成回执。已有completed／failed／cancelled终态不会因此变成未知；Dot工作已完成、只是朗读还没结束时也不会误报。

提示在同一Activity的重新连接后保留；新后台的空列表或重用ID不能确认旧任务。点击原有任务入口可查看固定说明，明确部分步骤可能已经执行，先在电脑核对再决定是否交办。“查看当前任务”保持提示并查看真实新列表；“关闭”只关闭对话框；“知道了”只清除内存标记并刷新卡片，不发送任务、开启麦克风、撤销操作或伪造完成。后续新的中断仍可重新提示。

头像、光环、字幕/进度布局和字体保持，主卡片仅在没有当前任务时使用既有警示色和固定文案。Activity重建后该RAM标记也会丢失；这不是持久化执行恢复，P1-02仅显式保存真实终态结果的边界不变。协议仍为2，候选后台版本仍0.14.15，当前实际部署0.14.13／APK0.9.7/code42未被替换。
