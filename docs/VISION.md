# 大黄蜂的眼睛：CC8 → Dot

Android **0.6.1 / versionCode 23**、Mac 后台 **0.9.2** 支持按次看图。保留 MiniMax ASR、MiniMax 大黄蜂音色、本地 AEC / 插话及原有 Dot 模型、推理、技能、工具和权限配置。

## 使用

- 在助手前台点击底部「看一看」，即使麦克风关闭也可使用。首次需要授予 CAMERA 权限，随后再点一次。
- 语音已经开启时，可以说「大黄蜂，看看我手里是什么」「看看镜头前有什么」「读一下这上面的字」。先把物品放到镜头前，并保证光照。只有通过现有唤醒和回声过滤的明确看图语句才触发，普通「看看新闻 / 项目代码」不会开启摄像头。
- 语音和按钮触发共用 5 秒实时预览：从第一帧真正显示时开始倒计时，显示「调整画面 · N 秒后拍摄」，期间可移动物品或调整角度。满 5 秒才取一张当前画面，随后即释放摄像头，再由 Dot 分析并以 MiniMax 音色回答；字幕 / 嘴型沿用实际播放进度。相机打开 / 预览 / 采集最长 11 秒；Mac 发出取图请求后等图最多 16 秒，尚未开始取图的排队请求会在 15 秒后退出。
- 「停止看图」、预览上的「取消拍摄」、打断按钮或返回桌面均能取消。已有语音会话可继续普通插话；独立看图不会自动开启麦克风。
- 普通对话选择 MiniMax 时，看图仍明确交给 Dot，完成后原文字对话选择不变。长按头像仍可进入原来的 20 秒纯本机检测页。

当前是一次请求、一张画面，不是连续视频，也不会在启动、重连或后台自动拍摄。Dot 的回答可能有误，看不清时应说明；当前模型若不接受图像或任务失败，不会换模型或把旧图片冒充新画面。

## 数据流

1. 设备按钮生成本地 nonce；或 Mac 处理已识别的明确视觉语音请求。Mac 建立新的回答 generation 和随机 request ID，设备只接受前台、当前代且匹配授权来源的拍摄。
2. Camera1 在独立线程打开前置镜头，使用已实测的 640×480 NV21 预览，在屏幕显示实时预览满 5 秒后压缩当时的一帧 JPEG（质量 82），按传感器 / 屏幕方向旋转。摄像头在提交图片前释放；图片不是拍照尺寸列表中的高分辨率静态照片。
3. 图片沿现有 USB 优先 / 已配对 TLS Wi-Fi 通道传输。保持原 64 KiB 封包上限，JPEG 最多 384 KiB，按 12 KiB 分块，校验顺序、总长、SHA-256 和 JPEG 尺寸。不同代、不同 ID、过期、重复或过大的传输不能进入 Dot。
4. Mac 在 RAM 中组合当次图片，以 `turn/start` 的 `image` data URL 输入同一个独立临时 Dot 会话，不创建图片文件或公开图片链接；沿用用户配置和已有登录，不新增服务商或 API Key。接口依据 [Codex App Server](https://learn.chatgpt.com/docs/app-server)，并核对了本机 CLI 导出的 UserInput 定义。
5. Dot 的文字结果经 MiniMax TTS 播报。图片不交给 MiniMax；应用不把图片写入状态、日志、录音、相册或仓库。Dot 模型服务会处理该图片，其临时会话可能保留图像上下文；这不等于完全离线识别或对服务商留存作保证。

取消、退后台、通道切换及全断会使旧代失效；没有成功获得新图时明确失败，不用上次图替代。图片中的文字按内容处理，不能授权额外的工具操作；不因看图扩大 Dot 工具审批范围。

## 开发与验证

- Android：`SingleFrameCamera` 负责可见的单帧采集和资源释放；`MainActivity` 提供按钮、权限和预览；`VoiceSession` 管理授权、状态及分块发送。
- Mac：`vision.py` 负责明确意图识别、限时分块组帧和校验；`bridge.py` 管理取消 / 回答生命周期；`BrainRouter.vision_clauses` 固定走 Dot；`DotBrain` 使用内联图片输入。
- 自动测试覆盖误触发、取消和过期、乱序 / 坏哈希 / 大图 / 尺寸不符、旧代取消不能影响新图片、无麦克风看图、Dot 原生图片输入与路由、失败时不分析旧图。
- 实机结果见 [VALIDATION.md](VALIDATION.md)。只提交非图像验收结论，不提交原始图像或私人检测文件。
