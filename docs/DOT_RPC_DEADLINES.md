# Dot RPC发送也受请求截止时间约束

后台0.14.21软件候选，设备APK和协议不变；当前实际后台仍为0.14.20，长期观察继续。该修正属于P0-06的明确超时反馈，也防止P0-02恢复时串行工作线程卡在本地管道发送中。没有调整模型、技能、工具权限、音色或采集规则。

## 问题与行为

旧`CodexRpc.request`先用阻塞管道写完整JSON，再开始等待回执的timeout。子进程不读stdin或读取过慢时，发送可超过预算甚至无限等待；发送期间还持有pending字典锁，使接收线程无法分发其他已到达回执。断连标志也不能唤醒OS阻塞写。

候选在请求开始时建立一个单调截止时间，序列化、等待发送锁、写管道和等待回执共用剩余时间。发送通过独立互斥锁保持一条完整JSON不可交错；实际写入使用本进程拥有的非阻塞stdin管道和有界可写等待，最长每100ms重新核对连接状态。响应/pending锁只包围短字典操作，不跨管道等待。普通通知及工具响应没有调用方请求预算时使用15秒发送预算。

发送锁等待超时且尚未写入时，只失败本次未发送请求，不污染另一条在途写入。半包超时或I/O失败后，流不再可复用：立即标记连接失败、唤醒pending等待方，拒绝在残缺JSON后追加新请求。实际写出的字节不会重发，未知结果不自动重试；后续明确新请求沿既有连接重建流程处理，不能把它当作原工作成功。

仅等待响应超时仍不主动重发或声称原操作没有执行。超时归brain/timeout，断管和断连归brain/transport_or_io，固定错误信息不包含请求正文、路径或系统异常原文。Dot最终完成回执与播报结果独立的规则保持。

## 验证

七项真实本地OS管道回归覆盖：写满超时及半包禁止复用、独立发送锁预算、断连唤醒、断管失效、写入与响应共用总预算、并发Unicode完整包且各接收一次，以及一个大包阻塞时仍可处理较早请求回执。公开固定字符串只在内存，fixture退出释放全部管道和线程，无设备、模型、网络或工具执行。

同一测试文件对26cf5fd基线执行：七项中六项断言失败、零fixture error，正常并发完整包控制通过；候选七项全部通过。配对来源/测试摘要和数字报告仅存私有目录`rpc-io-red-green.json`，不重写原失败。最终完整本地回归23项installer、803项host（4项私人录音opt-in跳过）、112项tooling及15项Java通过，固定质量检查和根目录/最小PATH的七项真实管道测试也通过；CI结果单独核对。

这些是本地管道故障和控制器错误分类的证据，不等于云端额度故障、任意工具后代清理、系统登录/睡眠或真实设备音频恢复验收。软件候选不替换当前0.14.20长期观察实例，不关闭完整P0-02/P0-06。

实现使用Python官方的[非阻塞管道写入](https://docs.python.org/3.13/library/os.html#os.set_blocking)及[可写事件等待](https://docs.python.org/3.13/library/selectors.html)。此路径面向现有macOS/Linux主机，不声称Windows管道支持。

## Dot 启动回执丢失

0.14.34 候选区分完整写出 `turn/start` 后的回执丢失与发送失败。完整写出后超时、断开或收到缺少有效回合 ID 的回执时，任务详情和错误指引显示「结果待核对」。动作可能已经执行，程序不会自动重发。发送阶段超时与明确拒绝仍走原有的失败分类。

无有效回合 ID 时，语音端停止接纳这个回合的结果与工具调用，关闭它拥有的 RPC 连接并请求守护进程清理。下次明确提出的新请求须等旧守护进程退出后才能创建连接。已入账的其他任务仍可查看。

回归使用真实 OS 管道和隔离的本地 JSON-RPC 子进程，验证回执超时、断管、畸形回执、明确拒绝、进程清理和下一条显式请求恢复。任务详情与指引由生产工作线程生成。测试不执行真实 Dot 工具，也未替换正在观察的 0.14.20 实例。

## 返回回执后核对截止时间

后台 0.15.44 候选在应答队列返回后再次核对原请求的截止时间。线程可能在队列超时前进入等待，却在截止时间之后才恢复调度并取得新回执。Python 队列此时可能直接返回该回执，因此接收完成后仍须检查统一预算。预算已经耗尽的 `turn/start` 继续按提交结果待核对处理，任务详情沿用既有的结果待核对指引。其他请求返回固定超时类别，待处理表均清理。截止时间之前收到的回执照常返回。

固定时钟回归在旧实现中复现两种方法、恰好截止及超过截止四处失败，同时保留截止前成功控制。真实本地管道另覆盖完整写入后超时、未写入等待、背压、断线和并发，检查不调用设备或真实 Dot 工具。
