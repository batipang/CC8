## 脱敏反馈

使用 [GitHub 兼容性反馈表单](https://github.com/batipang/CC8/issues/new?template=compatibility.yml)。只提交：

- 底部型号（不含序列号）、Android model、SDK 和公开固件版本号。
- 仓库提交、APK/host 版本、失败所在步骤、是否显式选择 shared-staging。
- probe 只复制 `shell_verified / uid / model / sdk` 四个白名单字段。失败时描述“无 USB / closed / 型号不符 / 签名不符 / 回执未完成”等类别，不粘贴异常全文。
- 安装、哈希、启动与音频结果分别填写。安装命令受理不算已装，已装不算已前台，已前台不算双工已验收。

不要公开完整 getprop、adb devices、安装/检测报告、账号、序列号、MAC/IP、配对、签名私钥、密钥、照片、录音或聊天。原始报告只在本机私有目录留存；报告保存权限未通过时先修复本机文件条件，不把重装当作保存失败的恢复方式。安全漏洞用 [私密安全报告](../SECURITY.md)，不要放在公开兼容性问题里。

维护者核对来源和版本后才更新表格。外部单次成功只记“外部报告可用”，不能推断全系列支持；无法复现保留未验证，不要求提交独有设备标识或私人音频来获得支持。

## 停止与恢复入口

工程入口未证实、SDK/UID/型号/证书不符、哈希或回执缺失时停止后续安装；按 [图示与排障](INSTALL_TROUBLESHOOTING.md) 处理。保留应用数据和原签名，不自动卸载、清配对或放宽权限。黑屏/不能正常开机时本工具不能救砖；保持安装流程停止，采用设备已有的官方支持途径。历史底层尝试不作为复位、解锁或刷机指引，也不推断原厂条款/保修结论。
