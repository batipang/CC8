# 已知插话波形的独立核对

后台 0.14.87 已部署，为 P0-01／P0-04 增加限时、可选的数值观察。code74 的首次检查在预备播报超时后结束，未进入观察；code75 已实际执行，独立窗口匹配未达确认条件，见 [当前部署](CURRENT_DEPLOYMENT.md)。MiniMax ASR／TTS、Dot、本地 AEC／VAD、唤醒与插话规则保持。它要回答的是“本轮已知近端语音的一个片段，是否出现在原始麦克风流中”，不替代完整双源声学分析。

```sh
./cc8 verify-device --runtime-root /absolute/live/workspace --capture --synthetic-barge --require-render-overlap --known-speech-evidence
```

默认只打印计划。实际执行追加 `--execute`，先核对后台能力和本轮运行身份，再访问设备。只支持独立的固定新问题插话测试；不能附加到停止词或批次验收，也不自动开启常驻监听。

## 数据与归属

固定 Tingting 语音仍在开麦前生成。该模式把临时文件放在运行目录的私有 `public-speech-fixtures` 子目录，文件夹 0700、WAV 0600。IPC 只传该子目录内的固定格式目录名、摘要／格式和原播报代次，不接受绝对路径、任意文本或音频正文。后台通过目录文件描述符及 `O_NOFOLLOW` 打开，核对当前 UID、权限、普通文件、单链接、大小上限与同一字节快照的 PCM／WAV 摘要；不删除调用者的文件。

观察只在当前前台测试收音和原播报均有效时开始，文件读取前后重核归属。绑定录音 epoch 和原播报代次，不把替代回答的参考拼接进去。只从已抵达的数据旁路复制，保持原有端点处理；不会借用抑制识别的扬声器测试模式，也不发起 ASR 或 Dot 请求。

原始 MIC 和原播报 RENDER 各最多保留六秒，八秒截止；旧 epoch、参考帧跳变、超过两毫秒的流时钟断点、非有限值、越界、退出和换通道均不能产生有效匹配。结束、取消或到期清零缓存，录音、参考及波形不写入文件／诊断／日志。临时文件仍由原测试在收音清理之后删除。运行目录保留空的私有容器不是录音留存。

## 匹配与解释

从已知输入的首个有效 20 毫秒块开始，取 200 毫秒模板。沿用已有播放观察的 8 kHz 归一化相关算法，要求峰值至少 0.55，且比 30 毫秒邻域外的竞争峰高至少 0.12。同一模板与原播报数字参考的最大相关度达到 0.45 时，保留 `reference_not_distinct`，不把可能的回声判作已知插话。

`known_speech_evidence` 只含方法、状态、输入摘要、有限帧数、相关度及匹配片段在本轮捕获中的相对位置。`matched_window_digital_render_ms` 是该片段时间范围内高于 −60 dBFS 的数字参考时长，不校正或推断房间传播延迟。匹配计算在 IPC 调用线程、会话锁之外进行；结束时再次核对归属，不能提交退出或换通道期间的旧结果。

`observed` 仅确认一个已知波形窗口，不能推出首个可听采样、真人说话人身份或扬声器实际同时发声。`first_audible_onset_measured` 和 `physical_double_talk_confirmed` 始终为 false。文件准备回执里的 `acoustic_playback_confirmed=false` 保持原意，独立观察不改写它。严格可信参考重叠条件也保持原值。

检查器先保存匹配／缺测，再完成原问题替换、设备停止回执和播后 20 秒观察；匹配未确认时保留失败并关麦收尾，不重复播放争取通过。数值格式、未知内容、错误摘要与虚假物理结论会被拒绝。固定批次审计不会将这种独立检查冒充完整矩阵。

## 验证范围

离线回归使用独立确定性波形覆盖混合输入、纯参考、无声、噪声、重复匹配、增益／直流／极性变化，以及窗口取消和缓冲清理。真实 Python 协议入口对照验证观察前后端点行为；IPC、路径／权限／链接、运行状态复核和分析并发另有回归。这些不替代实机房间声学、普通音量或识别准确率验收。

## code75 实机结果

冻结源码 `06ed109` 的 102.023 秒单轮报告保存 `not_observed`，整体以 `known_speech_window_unconfirmed` 失败并确认停采。独立观察已覆盖 64,320 帧 MIC 和 13,408 帧原播报参考；固定近端 PCM 为 45,318 帧，模板偏移 640 帧、长度 3200 帧。输入摘要与准备回执相同，临时文件清理确认。

相关峰 0.3417、竞争峰 0.1569、原播报相似度 0.1145。虽通过了数字参考重叠和同题替换，独立匹配没有通过 0.55 峰值条件；没有可用的确认窗口位置，也未测首个可听采样。观测结束后 raw 缓冲按同一读出／清理路径回收，没有录音可用于事后重拟合。

下一步须区分房间传递、前端处理和混合参考等可能影响。若引入传递模型，训练数据应在外部刺激启动前按因果边界截断，并用独立留出片段验证，再核对混合窗口；不能用同一混合片段拟合后当成独立证据，也不直接降低现有门槛。0.14.87／code75 记录时尚未实现；后续实现和现场结果见下节。

## 刺激前的独立传递核对（后台 0.14.88）

新增 `--known-speech-room-model`，必须与上述独立的 `--capture --synthetic-barge --known-speech-evidence` 一起显式使用。先检查后台能力，旧后台在设备操作前退出；已随后台 0.14.88 部署，保留 code75。首轮现场证据未达确认条件，见下节。

启动原播报并取得播放回执后，观察一秒已有输入；owner-only IPC 按同一 token 冻结已经收到的 MIC 和原播报 RENDER 帧数。收到固定边界回执前不得播放 Mac 测试语音；数据不足、代次改变、播放停止或边界被重复使用均不能授权刺激。边界之后收到的样本不得用于选取对齐位置、训练或验证。

分析仍在读出线程、会话锁外进行。按 8 kHz 降采样后的波形，使用前 400 毫秒 MIC 搜索固定 200 毫秒原播报模板；对齐仍要求相关度至少 0.55、竞争峰差至少 0.12。以 200 毫秒训练、200 毫秒间隔、独立 200 毫秒留出段核对传递，留出段不参与对齐选择。要求留出相关度至少 0.8、增益在预测的一半至两倍之间、极性一致。找不到对齐、模型验证失败或原参考覆盖不足时分别记录未确认，不能用后面的干净片段重新训练。

只有通过独立验证后，才以固定模型从边界后的原始 MIC 中扣除原播报预测，报告同一个 200 毫秒近端窗口的原始／残差信息和预测参考能量。`far_transfer` 只包含固定数值、计数及状态；原始与残差状态分开：原始相关度／竞争峰条件保持，近乎静音的原始或残差形状即使相关度高，也必须通过已有捕获测量底限（标准差 0.002）。残差匹配不能将原始失败改成成功。预测的远端能量也不是该混合窗口中实际远端出声的证明；`physical_double_talk_confirmed` 和首个可听采样标记仍为 false。

合成回归覆盖混合输入、纯远端、静音／近端单独输入、噪声、重复波形、留出段变化、后段完美参考不能改变前段对齐、参考缺失、边界与会话所有权、清理和严格回执。它们不能替代现场房间／前端处理、真实音量或完整 P0 矩阵。该模型仅供诊断，不进入现有 AEC／VAD 或识别决策。

固定源码 `2454d99` 的单轮测试实际取得刺激前帧数回执（MIC 16,960／原播报参考 16,864）。最终观察覆盖 77,120 帧 MIC／26,080 帧原播报参考，已知模板偏移 640 帧、长度 3,200 帧；准备文件校验、边界回执与结果核对通过。`far_transfer.status=alignment_unconfirmed`，对齐峰 0.1806、竞争峰 0.0574，未进入拟合或留出验证；报告中的训练／留出长度是预定分配。原始近端结果为 `not_observed`，相关峰 0.3539、竞争峰 0.1558、与原播报参考相似度 0.2636。
