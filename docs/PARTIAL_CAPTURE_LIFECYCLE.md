# 未成句收音的生命周期

0.14.10预定声学对照C03中，一段只有voice_detected、尚未成句和绑定代次的收音，在Home停采后遗留pending。0.14.11自动部署预检因此被严格owner_request_pending检查拦住；没有执行停服务、切源码或开麦。原报告与失败日志保留，不能称为已部署0.14.11或后台仍在执行该语音任务。

0.14.12源码让Endpoint只持有未成句trace：传输/会话/语音活动重置、Home停采及快速停止将其标为stale/cancelled；正常成句成功入识别队列、或唤醒门控拒绝后移交/释放所有权。识别队列主动discard时结束被取出的排队记录，不能遗漏；正在执行的ASR仍由其worker结束。重复清理幂等，不恢复捕获、不发模型请求，也不改已完成任务。

维护工具仍拒绝任何未完成任务。该变更不为任意pending提供忽略开关，不自动重试/取消用户任务。已有旧进程中的受控QA遗留需另外核实原始报告、固定ID和实例、无utterance/ASR/绑定代次、无活动workspace任务与双端关麦，并保留原始pending证据后才能作为特定升级的迁移例外；不能伪造它在旧进程中已完成。

软件回归覆盖三个重置的partial取消/幂等、三个重置不误结束已入队trace、快速停止保留已完成任务、Home真实控制器关闭采集、discard仅结束排队记录而不影响在途。均用现有Endpoint/Bridge/TraceBook和合成PCM，无设备、模型或新录音访问。
