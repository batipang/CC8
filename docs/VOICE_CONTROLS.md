# 播报语速与自然插话

后台0.16.6／助手0.9.61（code98）已部署，新增“设置 → 声音与自然插话”。选择舒缓、标准或稍快，并决定是否允许说新问题打断播报；“恢复默认”仅将本次编辑还原为标准／允许自然插话，仍需点“应用”。取消不提交。

标准严格恢复本机原配置的语速，舒缓和稍快分别使用其0.85和1.15倍，并保持MiniMax允许的0.5～2范围。音色、音高、情绪、ASR与Dot配置均不替换。字幕和嘴型继续使用当前实际返回的PCM与时间信息，不用倍速猜播放进度。校准仍只播“汽车人，变形！”，使用所选语速合成的同一段PCM作回声参考。

默认允许自然插话，保留原有普通音量新问题替换流程。关闭后，播报／近期播放的普通候选仍经过现有回声检查，但不暂缓原播报、不发起新任务或开启相机。明确“停一下”等现有停止指令及其回声抑制继续可用，手动停止不受影响。播报结束并退出原有3秒回声风险窗后，普通问题仍按原唤醒规则接纳。本地唤醒词检测保持原规则。这个开关不修改VAD、近端证据、ASR文本或停止词门槛，也不是电视／远场准确率已达标的证明。

只能在麦克风关闭、校准／识别／回答／播报／取景及队列均空闲时应用。拒绝时保留原值和正在进行的工作，明确提示先暂停语音、等待结束。设置不会打开麦克风、相机或发起模型请求。只保留在当前Mac服务内存中，USB／Wi-Fi切换不清除；Mac服务重启回到标准／允许自然插话及原配置，不额外持久保存用户数据。

后台通过真实握手／设置回执回报当前状态，界面不把发送成功当成应用成功。每次应用带原设置修订号，过期页面和重复请求不能覆盖新设置。页面绑定打开时的线路代次，连接改变后必须重开，不能借备用通道自动重投；旧线路、旧回答代次、Home后的回执不能恢复设置能力。旧后台或非MiniMax语音提供方不显示可用设置。

软件检查覆盖真实设置入口、忙碌／过期拒绝、实际MiniMax请求体、真实断句暂停与识别派发，以及编译后的设备收件／换线边界。声音主观偏好、真人插话、远场／电视条件保留最终验收，72小时仍最后进行。

用户词表、安静／普通／电视预设及“我说的是……”纠错继续留在P1-07。2026-11-09查阅[MiniMax官方语音识别调试页](https://solutions.minimaxi.com/debug/asr)及[官方CLI说明](https://github.com/MiniMax-AI/cli/blob/main/skill/SKILL.md)，没有取得当前接口热词参数的可靠支持证据；本批不向ASR添加猜测的字段，也不静默替换识别原文。
