# 明确启用的定时工作汇报（软件候选）

目标：补齐P1-03／P1-10的可选完成提示和定时汇报。默认关闭，只检查用户当次明确选择的聊天或登记成员范围，每5／15／30分钟检查一次；没有新增或可行动变化时保持安静。候选后台0.16.23／助手0.9.95 code132已接入私有状态、只读查询、周期调度和原生确认界面；整批验证、受保护CI与组合交付分别记录。当前运行设备尚未启用此功能。

确认启用时说明：保存必要的来源元数据、启用起点、已提示结果标识／版本摘要和送达认领，不保存结果正文、原始聊天、录音、图片或模型上下文。最多256个已提示版本，不自动淘汰；达到容量、时间范围超过31天、来源删除或时钟异常时停止并提示明确重新设置。修改／清除需要当前修订与明确确认；无关登记修订不改变冻结的成员范围。

通知先只提示本次最多3个新增完成答复的数量和来源，明确原答复尚未独立核验；不会把工作完成、通知送达或摘要播完混为一谈。通知索引不改动手动汇报的补播账本。完整结果和编号追问仍按用户明确请求取得的手动汇报快照处理，后台提示不偷换旧语音编号。自动朗读完整定时摘要、最近一轮结果的专用查看入口继续开放，不以本次数量提示代替整项P1-10交付。

每次从启用起点重查至本次冻结截止，包含迟到收集的结果，按真实来源／回合／结果及版本去重。部分覆盖或失败不等于零成果，不提前推进读取起点；容量和原有读取上限需要明确展示，不能推断其他来源没有结果。

调度只在CC8前台已认证连接、整条管线空闲且不在既有提醒安静时段时读取／通知。配置确认可明确准入本次前台连接；重启或Home后仅持久配置不会自动准入新连接，正常用户开始语音后可恢复其已启用配置，暂停麦克风后同一前台连接可继续提示。维护无自动语音开关、测试独占锁、Home和线路变更不得触发新的扫描或通知；不自动打开麦克风、相机、窗口选择器或后台界面。

发送前原子认领；只有实际CC8播完或匹配的通知中心回执才记已提示。中断、异常、认领耐久性未知或重启遗留不自动重发，明确显示送达未确认。清除／重新配置后旧回执不能改变新配置。暂停通知不取消原工作；用户之后的明确手动汇报仍可读取原成果。

实现检查：私有存储／协议、实际调度器与真实控制器、编译后的原生窗口、Home／线路／旧回执、未确认认领、安静时段、范围和容量。默认不请求真实通知权限、不采集媒体、不读取实际聊天；真实来源与系统通知授权仍在最终环境队列，72小时最后。
