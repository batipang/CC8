# 主人／访客模式

软件版本：后台 0.16.36、助手 0.9.128（code166）。主人保留原 Dot 配置、模型、技能和工具；访客使用独立 MiniMax 文字问答及已有语音管线，不读取主人聊天、任务结果、提醒、偏好或词表，不执行桌面操作、会议、流程或看图。

## 使用

在助手右上角点击大脑状态，或在设置选择“主人／访客模式”。等待当前请求结束后选择“进入访客”。助手立即停止收音和播报、清除私人画面与对话框；待设备和 Mac 确认后显示“访客 · MiniMax”。切换本身不会重新开麦，可再点击“开始语音”。普通打开应用仍保留原有一次自动语音流程，重连不会自行开启收音。

访客界面只保留独立问答、语音开始／暂停和身份说明，主人专用入口由设备及后台共同限制。说“让 Dot 帮我……”不会绕过访客路由。访客对话只在内存中保留最近最多八条已完成消息，不混入主人历史；退出时清除访客上下文。当前访客问答没有联网搜索或工具，实时问题需要如实说明能力限制。

恢复主人模式必须在当前 Mac 的主人账户发起；设备按钮和语音不能选择主人角色。在仓库根目录查询实际修订，再明确恢复：

```sh
python cc8-assistant/host/identity_cli.py status
python cc8-assistant/host/identity_cli.py owner --revision 1
```

上面的 `1` 只是示例，须使用状态返回的实际 `state.revision`。`ok=true` 表示本次设备已确认；超时或断线的结果是未确认，不自动重试。先查询状态，检查 `ready` 与 `device_applied`，不要盲目重复切换。模式、界面存储或上下文清理失败时关闭访问，不静默回到主人。

## 隔离与回执

`guest_brain.py` 不检查调用方传入的主人历史，只发送固定访客指令、访客自己的完成消息和当前问题，没有 Dot、工具、文件、工作汇报或搜索入口。文字会发送给现有配置对应的 MiniMax 服务，凭证不进入提示词或设备协议。每轮请求独占传输对象，迟到取消不会关闭下一轮请求；不完整结果和非法 Unicode 不进入完成历史。

`brain_router.py` 的访客分支位于委派、偏好及工作汇报之前。模式变化使旧生成器和旧回调失效，逐句输出仍检查身份。主人 provider 和完整 Dot 配置保留，不以访客方案替换主人权限。

`identity_mode.py` 以私有目录、私有文件、原子替换和比较后更新保存模式修订，拒绝损坏文件、链接、旧修订与不确定保存结果。`IdentityPreferences` 在 Android 私有存储保留已确认身份与限制性的访客意图；存储失败不会确认新角色或退回主人。

`identity_runtime.py` 接入实际 `Bridge`：先发身份挑战，确认后再发送对应界面握手。确认前不接收录音、不派发文字任务，也不发送私人事件或播放音频。访客使用独立内存任务区、结果续读状态及默认语音／语言／听音设置；主人返回时恢复原对象和会话设置。提醒、工作进展和定时流程在查询及交付前检查模式。完成的流程保留终态回执，不会被误判为永远忙碌。

`identity_state` 下发随机 token、模式修订和授权来源；`identity_applied` 必须在同一连接／激活 token 上确认同一模式、修订和随机 token。回执只能确认状态，不能选择角色。`ready` 是主机保存及上下文处理完成，`device_applied` 是设备确认，两者不能互代。Mac 恢复入口在会话锁外有界等待，迟到回执可确认原操作；重连重新确认已保存的授权，不重复执行切换，也不开麦。

设备的 `IdentityState` 限制旧主人回执、旧连接及修订回退。所有 Activity 异步回调在实际执行时检查身份代次；切换关闭已有私有对话框，过期对话框不能重新显示。音频、字幕及来源还保留原来的路线、录音会话与回答代次检查。USB 仍优先于已配对 Wi-Fi。

Mac 私有 socket 的 `identity_status` 和 `identity_owner` 只接受固定字段。访客或身份未确认时，普通播报、桌面任务与拍照 IPC 被拒绝；主人账户的只读诊断与恢复入口保留。CLI 检查 socket／目录的所有者、权限和类型，拒绝链接、重复 JSON 字段及不完整响应，不自动重试。

## 升级与回退

升级计划和三方候选／恢复检查读取私有身份状态。访客状态下，缺少身份读取能力的旧后台不能作为恢复目标；保持原文件，不复制旧状态覆盖它。需要退回旧程序时，先由主人在 Mac 明确恢复主人模式并核对结果，再重新准备恢复计划。手动跨检出目录迁移时必须连同 `identity-mode.json` 保留当前状态；不能丢弃文件获得默认主人身份。

旧后台仅在设备没有访客意图时保留主人协议兼容；已选择访客的设备不会接受无身份协议的主人握手。新后台需要支持身份确认的助手版本，部署时按已验证的成对软件进行更新。

## 验证范围

自动化覆盖实际访客请求正文、主人历史哨兵、委派绕过、旧生成器／回调、迟到取消、私人文件保护、修订冲突、提交失败、伪造角色、当前路线握手、确认前录放拒绝、主人设置恢复、真实 Unix socket 与 CLI。实际 Java 源码测试覆盖 Android 存储适配、接收边界、Activity 排队回调和对话框清理，并与真实 Python 后台生成的身份包往返确认；Android 编译及 lint 另行执行。

这些检查不等于 CC8 上的现场验收。实际设备的视觉效果、真人语音与切换体验留在最终验收队列；不为验证本功能自动开启实际摄像头或麦克风。72 小时冻结验收仍为最低优先级。
