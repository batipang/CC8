# 命名工作流程

P2-01 软件已随后台0.16.27／助手0.9.99 code136部署。Mac定义、串行执行、结果回执及只读定时已接入CC8原生编辑／确认／结果入口；PR476与主分支各八项CI、原签名构建／lint及正式页面自动检查通过，范围见[当前部署](CURRENT_DEPLOYMENT.md)。尚未在本次维护中执行生产流程或真实取景，不能据本页把P2-01完整验收勾选完成。

## 定义和数据

预置“晨间简报”“任务进展汇总”“看图识字”，初始都不开启定时，汇报来源未绑定。最多保存 8 个流程，每个 1～4 步；名称和步骤标题各 40 字，输入 500 字。支持一般交办、只读联网搜索、明确来源的工作汇报和本次取景 OCR。步骤按顺序执行，后续步骤使用各自明确输入，不把上一步的网页／聊天／图中文字自动变成新指令。

配置仅在用户明确保存时写入 `device-access/private/voice-runtime/workflows.json`，目录 0700、文件 0600；构造组件、查看内置模板不会创建存储或启动工作。读写检查链接、文件所有权、修订号和跨进程独占锁，原子替换后确认持久化。流程自身仅在当前后台内存保留结果，不把正文写入定义或定时记录，也不追加到普通语音的本机 history。一般交办／OCR 仍使用原有 Dot 配置、上下文和会话留存规则，未关闭 Codex 既有历史；搜索／汇报文本不会自动送给后续模型。现有任务页允许的显式结果保存仍由独立入口决定。

每步接受对应本机生产者的操作回执：Dot 匹配的完成 turn／最终答复、MiniMax 正常完成的可见答案流、成功搜索响应、校验来源和时间窗口后的只读工作汇报。模型说“已完成”不替代操作回执。回执不表示答案事实或工具结果已经独立核验。

## 手动运行

通过已认证前台通道请求 `workflow_request`：查看、编辑、准备、明确确认运行、取消、查看单步结果。编辑和准备要求停麦且没有其他任务／校准／播报。准备阶段冻结流程、所选汇报来源和当次连接所有者，生成 90 秒一次性确认凭据；不调用模型、网络或摄像头。定义修改、切换连接、过期及重复请求会使旧确认失效。

实际执行进入原有唯一响应队列，不创建第二个 Dot 工作线程。流程设置 300 秒执行期限；底层有界 I/O 的退出清理可能晚于期限返回，过期的新操作及结果不再接纳。当前步骤失败、取消或回执不明时停止后续步骤，保留已经确认的单步结果，不自动重跑。最后一步回执与父任务完成状态在同一所有者事务中提交；后续停止朗读不能把已完成工作改为失败。

OCR 只允许作为第一步，必须在当次前台确认中明确同意取景，并携带客户端设置的单次摄像头 nonce。后台复用可见 5 秒预览和有界图片收件箱，不复用旧图，不导出 JPEG，不允许定时取景。客户端取景授权另绑定本次流程开始回执、连接和执行代次，15 秒内有效、只消费一次；切换连接或取消不沿用。取景结束恢复同一文字任务的播报所有权。

完整结果按单步查看，每步最多 8000 字并标明截短。播报只读有界摘录，最长 1600 字；网页正文和事实未核验、来源标注日期与检索时间的区别在原始结果中保留。执行完成与设备播完分开处理，缺少匹配的设备播完回执时不宣称送达。

## 定时运行

只能为只读搜索及已明确绑定来源的汇报启用定时；一般交办和 OCR 不允许定时。支持 5／15／30 分钟间隔，或北京时间指定钟点和星期。每次显式修改从 Mac 当前时间建立新的配置窗口，客户端不能回填启用时间。

定时器没有新线程，通过既有心跳在前台、认证连接、音频空闲及非安静时段提交同一个串行响应队列。只有明确配置或新的正常开始语音身份才能建立当次前台运行许可。换线、Home／停止、维护测试租约、时钟回退和所有者变化会撤销许可；普通重连和维护结束不自行恢复。新的许可跳过其建立时间之前的时段。允许的迟到窗口内只处理当前最新时段，不累积补跑历史时段。

每个时段先原子保存一次性 claim，再提交执行。队列受理不算执行成功，执行成功也不算设备播完。记录只含流程／定义哈希、时段、领取时间、执行状态和摘录送达状态，不含结果正文。进程重启或不确定状态不重发同一时段。最多保留 256 条领取记录，达到上限停止领取；显式清除记录会在同一写入中先禁用全部定时，之后重新启用从新窗口开始。
