# 显式会议模式（开发中，尚未部署）

会议模式独立于日常语音。前台页面在获得参与者同意、麦克风权限和一次性启动确认后，才能开始一段录音；暂停后继续需要重新确认。关闭页面、Home、断线或取消会停止采集，重连不会续录。硬件释放未确认时拒绝新的采集。当前不支持保存原音，录音片段仅在内存中用于 MiniMax 转写。

单场最多一小时，单段最多 30 秒、单声道 16 kHz，最多排队两段。排队满、识别失败和传输缺口都有明确状态，不把缺字或未确认结果解释成无人讲话。转写文字可以按片段查看、复制和校对；分页游标来自服务端，不按 Android 的 UTF-16 长度自行计算。说话人标签不是身份识别，片段时间也不是逐字时间戳。

## 导出和删除

结束会议并等待转写返回后，可明确选择 TXT 或 JSON 导出。导出包含全部片段、缺口和未确认标记；人工校对保留原识别文字。超过容量会拒绝整次操作，不静默截断。文件保存位置由真实回执给出，可在 CC8 复制路径，然后在当前 Mac 打开。这个版本的导出不包含 Dot 总结或翻译。

导出目录为当前运行工作区的 `device-access/private/voice-runtime/meeting-exports/`，被 Git 忽略。构造组件、启动后台和打开未导出过的列表均不创建转写文件。目录 0700，文件 0600。每份导出使用一个私有文件夹，同时包含 `meeting.txt` 或 `meeting.json` 和 `receipt.json`；先同步正文和校验回执，再原子发布文件夹并同步父目录。文件夹标识由会议 ID、修订和格式组成，正文不作文件名。

最多 16 份导出，正文单份最多 2 MiB，目录内容合计最多 16 MiB。不自动清理旧文件。重复导出同一修订且内容一致时返回既有文件；内容不同、未知目录项、链接或异常权限不会被覆盖。路径和文件校验在实际读写时核对，目录被替换、同步失败或部分删除均不能报告完整成功。故障留下的有界不完整记录可重新查看，再用当前回执明确删除；未确认的写操作不自动重试。

“删除会议”清除内存中的转写和校对；已导出文件需在“已导出文件”中单独删除。删除绑定用户选中的文件标识和 SHA-256，不使用任意路径，不能静默改删另一修订。重启后可以列出、删除导出记录，但不会自动加载成新会议、启动识别或重播录音。

## 接口与所有权

所有控制都通过原有认证连接的 `meeting_request`。`exports` 只列回执；`export` 要求会议 ID、精确修订、格式及明确确认；`delete_export` 要求文件标识、精确哈希及明确确认。没有音频包协商或前台有效连接时不能开始录音。文件操作不进入实时采集期间，日常对话、相机、提醒和工作流程不能抢占会议音频。

原生页面回执绑定请求和动作，旧窗口、旧路线、旧修订及旧代次不能替换新页面或重新授权录音。校对失败保留草稿。导出格式、内存删除和文件删除使用当时选择的不可变标识，不能跟随后台新状态改换目标。

## 验证范围和剩余工作

定向回归使用合成 PCM、模拟识别回执、真实状态机、私有临时文件和受控原生控件；覆盖控制协议、录音资源释放、分页重建、路由隔离、校对、完整导出、取消、文件替换、同步失败和部分删除。Android 调试编译及 lint 只证明软件构建可用，未启动设备麦克风或摄像头。

下一步是把完整会议文字交给 Dot 做修订绑定的总结和翻译，支持查看完整结果与导出。完成该批次后再统一运行完整回归、正式构建、受保护 CI 和部署。真实 MiniMax 会议识别效果、30 分钟获参与者同意的会议及主观体验留到最终验收，不据离线结果关闭 P2-03；72 小时验收仍排最后。
