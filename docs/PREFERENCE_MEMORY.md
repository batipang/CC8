# 显式偏好记忆

0.16.11／助手0.9.71（code108）已按原签名部署，独立偏好库及六项正式设置／取消界面自动核对通过。实际范围见[部署记录](CURRENT_DEPLOYMENT.md)；不等于真人个性化完整验收。

## 使用

CC8“设置 → 偏好记忆”可查看、新增、修改内容、删除、关闭／开启及清空。每条显示来源、北京时间更新时间与适用范围；同名（不区分大小写，采用NFC文本规范化）修改覆盖旧值。修改界面须先暂停语音并等待任务、播放、校准和取景结束，不自动停任务或开麦。关闭后保留记录，但不提供给新的模型回答；删除与清空不恢复旧副本。

正常语音已开启时，也可明确说：

- “大黄蜂，记住，我的称呼是老王。”
- “把记忆中的称呼改成老李。”
- “忘记称呼。”或“删除记忆中的称呼。”
- “查看记忆。”“关闭记忆。”“开启记忆。”
- 说“清空记忆”后，在同一次收音连接中于 30 秒内说“确认清空偏好记忆”。该确认只能使用一次。期间若停止、换线、提出其他请求或偏好库已更新，须重新发起。设置里的清空仍有独立确认。

“记住”需要明确的偏好名称及“是／为／叫／等号／冒号”后的内容；缺字段时提示补充，不猜测，保存后读回实际名称和内容。“把记忆中的……”只修改已有确切名称。询问“记住……是什么意思”或带“吗／么”的不明确问句不直接保存，可使用设置明确填写。不会从普通聊天、照片、网页或模型推断自动提取记忆；通用文件删除与普通查询不作为记忆写入指令。没有提供给模型的记忆写入工具，未识别的管理请求不得冒充已保存。

## 保存与模型范围

仅在当前Mac的私有运行目录`preference-memory.json`保存明确记录，最多24条，每条名称40字、内容200字；值允许换行，拒绝不可见控制字符。文件0600、目录0700，写入通过独立有界文件锁、修订核对及原子替换。首次查看不创建文件；异常文件保留并报告未确认，不重置为空或自动覆盖。重启从真实文件读取；未确认写入不自动重试，先刷新核对。此库与提醒、结果档案、录音、Dot配置和签名密钥分开，配置备份不会自动导出偏好正文。

开启且有记录时，当前Dot及MiniMax回答会收到这些偏好数据，所以内容也会交给所选模型服务；本机存储并不表示只在本机推理。旧Hermes兼容路径未增加个性化注入。数据明确标记为用户偏好，不授权工具、读取文件或发送消息；当次要求优先，同一主题的矛盾条目按更新时间采用最新明确指示，不确定时询问。不同名称不会被程序擅自合并。

偏好按更新先后传给模型。同一秒内多次保存时，后提交的条目排在后面。Mac 时钟回拨时，新修改沿用库中最近的更新时间，直到系统时钟追上，期间仍按提交顺序区分。这项规则重启后仍有效，兼容已有偏好文件。

变更偏好后，下一次普通／看图回答更新本助手的RAM对话缓存；Dot会重建自有临时语音上下文，避免删除或关闭后继续注入旧偏好。记忆管理指令本身不进入普通模型对话历史；已有任务结果不因此改写或重做。不会修改原桌面聊天、模型、权限或工作环境。原始请求或已生成文字仍可能存在于既有任务卡、原聊天或第三方服务；删除本库不能承诺同步清除这些历史记录。
