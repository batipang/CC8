# 明确的语音识别更正

后台0.16.7／助手0.9.63（code100）已部署，支持当前语音会话的可撤回更正。说“我说的是常州，不是沧州”时，只在最近问题中逐字查找且唯一定位“沧州”，提出保留其他文字的替换；不依赖ASR一定插入逗号，也支持“常州而不是沧州”。找不到、重复出现或只匹配数字／名称的一部分时，明确要求重说，不模糊猜词。金额、负号、小数和名称边界保留，不把150中的50或负三点五中的三点五当成完整字段。

也可以在“我说的是”后重说完整的新问题。没有明确旧词替换关系时，后面的文字整体作为候选新问题；只说“常州”就只会提出“常州”，不会猜测要保留哪个旧问题或自动加上天气等上下文。草稿会完整展示原问题和候选问题，确认前应核对全部内容。

设备前台弹出“更正草稿 · 尚未提交”，可点击按钮或说“确认更正／撤回更正”；“查看更正”重新展示当前草稿。草稿及原问题最多512字，仅存在当前已认证线路、麦克风会话的RAM中。最近问题两分钟后不再可作为来源，草稿自提出后两分钟失效；停止、Home、换线、睡眠退出对话或新的普通问题／文字请求清除草稿。仅停止播报或撤回草稿时，可继续更正尚未过期的同会话原问题；暂停麦克风、Home或换线则连原问题上下文一并清除。重连不恢复草稿，不开麦；旧后台／设备能力不足时不生成无法核对的草稿。

提出、查看或撤回草稿都不调用Dot、不创建任务、不改变原任务回执或模型对话历史。纠错内容中的“看一看”等词不会在草稿阶段打开摄像头。音频提示只提醒核对屏幕，不朗读精确提交口令，以免自身提示成为确认输入。

只有明确确认才通过现有文字请求事务提交一个新请求，界面标记“已确认更正”。不静默覆盖ASR原文，不恢复或重放原工具回合，不撤销已执行操作；原任务已完成的状态保持。新请求仍由原Dot／MiniMax分工、真实工具权限与实际完成回执管理。摄像头新输入仍需明确的新取景请求，不借用旧图。

按钮只发送一次随机请求ID、草稿ID和确认／撤回动作，不能从设备替换正文。语音确认、撤回或查看在入队时也绑定当时的草稿，期间若草稿被替换，旧指令不会作用于新草稿。重复、过期、旧线路和旧页面请求不重投。提交回执不明时先核对任务，不能自动再执行。设置和草稿不增加录音、屏幕图像、识别全文或原始报告的持久留存；用户明确保存终态任务时沿既有保存规则处理。

软件验证覆盖真实识别到响应的准入、草稿与任务事务、原回执保持、停止／换线／过期、数字／名称边界、提前看图拦截以及实际Java收件与弹窗按钮。它补齐纠错操作，不等于原ASR准确率、真人／电视条件或完整P1-07已达标；这些验收仍保留，72小时最后进行。
