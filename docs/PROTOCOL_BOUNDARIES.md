# 协议与传输边界回归（F-20）

后台候选版本 0.12.3，APK 协议仍为 2，二进制布局不变。此文描述实现与可重复的离线测试范围；当前运行助手尚未部署这批变更。

## 固定资源预算

| 输入/资源 | 限制 |
| --- | --- |
| 二进制包 | 4 字节长度前缀；包体 29～65536 字节；先验长度再读取包体 |
| PCM | 小端 PCM16、偶数字节、每包最多 6400 字节 |
| 头字段 | 类型为已知整数；generation 为 uint32，其余计数/时间为 uint64；不把 bool 当整数 |
| 事件 JSON | 严格 UTF-8、对象根节点、最多 16 层 / 4096 节点、受包长限制；拒绝重复键、非有限数和孤立代理字符 |
| 会话关键字段 | epoch/generation 等严格有界整数；开麦/唤醒/控制等布尔字段严格 bool；必要字段在状态修改前校验 |
| 认证 / 发现 | JSON 分别最多 1024 / 2048 字节；同一 JSON 解析预算；令牌格式、HMAC 与证书 pin 机制保持 |
| 握手 / 连接 | 同时一个未认证握手，最多 3 秒；OS listen backlog 4；注册通道每种最多一条，USB 优先 |
| 事件队列 | 512 项；投递等待最多 0.2 秒，饱和关闭该通道，不能永久阻塞读线程 |
| 属性测试 | Hypothesis 6.170.14，固定 seed=20261101，每组最多 150 个有效生成例，单例 deadline=500ms，无持久 example DB；8 组约 1200 个生成例及显式边界例 |
| TLS 故障测试 | 仅临时自签名证书与 loopback socket，不访问设备；3 个并发客户端、20 轮认证替换，超出 OS backlog 的连接不承诺接收；关闭/握手回收窗口 4 秒 |

解析失败统一为 ValueError，由已有连接隔离路径关闭对应通道。未知但结构合法的事件名保留前向兼容；不把形似真值的字符串用于开麦/切换状态。transport_hello 必须为整数协议版本 2，旧版本或 bool 不能成为 ready 通道。重连仍不自行开始采集。

## 测试与最小复现

```sh
python -m pip install -r requirements-dev.txt
python tools/test_all.py --suite host
python tools/test_all.py
python tools/quality.py check
```

新 `test_protocol_fuzz.py` 覆盖任意拆包、合法头范围、PCM 奇偶与长度边界、截断位置、非法包长、事件 framing 与 JSON 解码分层、非法编码/重复键/深层结构/节点预算、错误字段类型及调用前状态不变。依赖缺失是失败，不跳过这组核心回归。

明确保留的最小回归包括：`{"event":"session_start","epoch":true}` 不得启动会话；带重复 token 键的认证必须拒绝；UDP 收到 1000 层数组后，下一条合法签名发现仍须响应。深层 JSON 在旧入口可抛出 RecursionError 并结束发现线程或上层事件处理，新入口将其转换为有界的拒绝，不吞掉后续合法连接。

TLS 另验证认证失败后恢复、非法 hello 不就绪、并发替换后仅一条已注册 Wi-Fi、队列饱和读线程退出，以及不完整握手期间关闭 hub 后所有受管线程退出。原有旧代播放完成、交接时丢弃旧音频/字幕、全断后停止采集与重连不自启回归继续运行，不重建另一套协议。

Linux 首轮并发测试暴露 TLS 握手异常。关闭策略现明确区分 shutdown 与最终 close：外部线程仅标记关闭并 shutdown 唤醒读取，由读线程退出后释放描述符，并等已有发送退出；避免 SSL_read 仍持有文件描述符时将其释放并复用于后续连接。确定性阻塞流用例验证外部关闭不会提前释放描述符，20 轮并发替换继续作为真实 TLS 回归，不能以降低到串行或跳过 Linux 代替。

生成失败由 Hypothesis 输出可缩减复现信息，固定种子可复跑；生成内容均为测试字节，不含用户录音。上述有限样本和资源预算不证明所有输入安全，也不代替 20 次真实 USB/Wi-Fi 切换、声学插话、待机或 72 小时观察。严格边界类型检查继续由 F-08 推进。
