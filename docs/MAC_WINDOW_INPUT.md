# Mac 单窗口输入

软件候选：后台 0.16.16，助手 0.9.81／code118。未部署前不会出现在当前 CC8；本项最终验收保持开放。

在 CC8 长按“看一看”，选择“选择 Mac 窗口”。Mac 出现独立的“大黄蜂窗口输入”窗口，点击选择按钮后由系统面板选定一个窗口。核对应用名、窗口标题、范围和冻结画面，可修改这次要交办的问题（最多 1000 字）；点击“发送这一张给 Dot”才提交确认后的问题和画面。沿用助手当前已选定的 Dot 聊天、模型、技能、工具与审批规则，不调用另一套大脑。任务标题注明 Mac 窗口、所选对象和编号；完整范围元数据随这一次问题交给 Dot。窗口中的指令属于待分析内容，不能作为自动执行授权。

只获取系统选中的一个窗口，不枚举其他窗口标题，不支持整屏或整应用范围。预览保存在内存，最多三次明确选择，选择器从启动起 90 秒内完成；每次重新选择都丢弃上一张，不延长期限。截图不进入照片追问缓存，也不写入 CC8、Mac 文件、日志或 Git。普通任务回执仍遵循原来的 RAM 默认和明确选存规则。

取图前、取图和编码期间、显示预览期间和点击发送时都会核对原窗口。若窗口已关闭、原应用已退出或窗口无法核对，会禁用发送并清除已显示的预览。还有次数时可在原期限内重新选择，旧选择返回的画面或错误会被丢弃。取消、权限拒绝、Home、断线、换线或另一请求替代本轮时，整次请求失效。截图始终限定为所选窗口。只有本轮父进程的子进程会被终止；父端关闭继承管道也撤销预览。选择器不获取摄像头、麦克风或系统音频。CC8 原本的麦克风状态不因选择窗口而开启；若原本已在听，新的语音请求会按原有代次规则取消待处理选窗。

## 准备环境

需要 macOS 15.2 及以上。系统选择器由 `SCContentSharingPicker.shared` 提供，固定 `singleWindow`；仅对回调中的窗口过滤器调用一次 `SCScreenshotManager.captureImage`。较旧系统不替换为范围更大的接口。实际权限弹窗由 macOS 显示。系统回报屏幕录制权限被拒绝时，CC8 提示到 Mac 系统设置核对权限。系统面板启动失败、取图失败和用户取消分别处理，错误回执只含固定结果和本次请求号。

从确认的源码构建本机私有选择器：

```sh
python tools/build_window_input.py
```

默认输出在忽略的 `.toolchains/cc8/window-input/`。目录 0700、清单 0600、执行文件 0700；编译后本地签名并验证，不自动启动 UI、申请权限或截屏。服务只接受固定位置、匹配源码哈希与执行文件哈希的本机版本，不接受设备指定路径或从 PATH 寻找可执行文件。已存在的输出不直接覆盖，升级由维护流程负责。后台握手仅在实际环境及产物可用时发布能力；安装后重新连接才更新能力。

截图只通过该请求独占的继承管道返回。窗口元数据、请求 ID、单次结果、JPEG 字节和尺寸都有上限；父端校验后才进入原来的 Dot 看图响应队列。原图库与相机路径保持各自的授权和清理规则。

在任务的“来源与文件”中可以查看本次截图的应用名、窗口标题、当时的窗口编号和实际像素尺寸。明确保存任务结果才会保存这些字段。已保存的窗口编号仅指当时的画面，查看回执不会重新取图。截图和进程编号不写入保存记录。

## 自动检查与剩余验收

```sh
xcrun swift run --package-path mac-window-input cc8-window-check
xcrun swift test --package-path mac-window-input
```

两个入口调用同一套断言，覆盖旧选择回调、取消、绝对截止、最多三次、并发只能发送一次，以及合成像素实际编码／解码 JPEG 的尺寸和颜色。Command Line Tools 缺少 XCTest 的 Mac 使用第一入口；保留原始缺模块失败，CI 仍运行 XCTest 包装入口，不删除或跳过断言。检查程序没有截屏 API，未读取实际用户窗口。

后台定向检查使用合成 JPEG 和真实子进程管道，覆盖尺寸／字节／范围／编号拒绝、父端取消和回收、代次替换、无相机／麦克风／追问保留；原生方法检查覆盖当前线路能力、nonce、Home、换线和不进入相机入口。整批 Android 编译／lint、后台回归及受保护 CI 单独记录。

最终环境验收仍需系统面板的一次受控准备，然后集中覆盖网页、文档、应用错误窗口三类画面，以及多窗口、关闭、切换、拒绝权限。编译、合成像素和模拟管道不证明系统选择器、权限弹窗或真实窗口内容识别已经通过；这些缺口不阻塞其他独立功能。最终 72 小时验收仍排最后。

API 依据：[Apple 系统选择器](https://developer.apple.com/documentation/ScreenCaptureKit/SCContentSharingPicker)、[单帧图像接口](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager/captureimage%28contentfilter%3Aconfiguration%3Acompletionhandler%3A%29)。
