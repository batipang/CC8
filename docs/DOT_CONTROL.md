# 从当前 Dot 聊天操作 CC8

Android **0.7.0 / versionCode 24**、Mac 后台 **0.10.0** 增加桌面拍照返回入口。当前 Mac 的 Dot / Codex 可复用两项技能：

- 「让大黄蜂播报：会议还有五分钟开始。」→ `cc8-announce`：使用现有音色朗读，并确认设备播放结束。
- 「让大黄蜂拍一张照片，显示在这里。」→ `cc8-camera`：CC8 前台显示 5 秒实时预览和倒计时，取一张当前画面，关闭摄像头，返回 JPEG，在发起请求的 Dot 聊天中显示图片。

这两项操作沿用现有 USB 优先 / 已配对 TLS Wi-Fi 通道，不启用网络 ADB，不改变大脑、音色或麦克风开关。普通打开助手仍按用户设置自动开始语音；只做桌面操作的准备使用 `launch.py --no-open` / `--no-auto-voice`。

## 入口与回执

从实际连接设备的工作目录执行，不要在另一个克隆中重复启动后台：

```sh
# 请求一张新照片；stdout 只有元数据和成功文件的绝对路径
python3 cc8-assistant/host/camera.py

# 播报原文；也可用 --file 传入 UTF-8 内容
python3 cc8-assistant/host/announce.py <<'CC8_LITERAL_TEXT'
会议还有五分钟开始。
CC8_LITERAL_TEXT
```

服务是本机权限 0600、父目录 0700 的 Unix socket `device-access/private/voice-runtime/announce.sock`。拍照请求携带新的客户端 request ID；设备还用既有配对密钥校验连接挑战、请求 nonce 和代次的签名，拒绝旧连接和重复授权。回执需匹配客户端 ID，校验 JPEG 尺寸、长度和 SHA-256 后才保存。只有 `status=completed` 才取得新照片；回执丢失、失败、取消或超时不自动重拍，不能用旧图代替。

`camera.py` 将新照片保存到被 Git 忽略的 `device-access/private/photos/`，目录 0700、文件 0600。当前 Dot 应查看该文件，并用返回的绝对路径内嵌图片 `![CC8 本次拍摄](/绝对路径/照片.jpg)`，不能只给下载链接或声称显示成功。文件保留供聊天查看，不创建公开链接，不自动转发到其他服务或联系人。

## 状态和取消

助手必须在前台、连接已认证、相机权限已授予且未校准 / 执行其他看图任务。实时状态可沿用 `device_control/status`，不能只凭缓存文件认定在线。USB 可用时可用不自动开麦的维护入口打开助手；仅 Wi-Fi 且助手在后台时，目前需要用户先打开界面。

桌面拍照作为新的明确动作会取消旧回答；不会调用内部 Dot 再分析一次，也不会自动播报。用户可以在 CC8 点「停止看图 / 取消拍摄」。退出前台、通道变化 / 全断、客户端断开和超时都会取消未完成的拍摄，旧代结果不能进入新请求。拍摄并提交后取消不能撤回已提交内容。

原语音／按钮「看一看」继续使用内存图片交给内部 Dot 分析、MiniMax 回答，不因新增桌面技能而保存图片。只有明确请求返回到聊天的桌面拍照会创建 JPEG 文件。

## 安装技能与验证

可复用技能源码位于 [cc8-camera](../skills/cc8-camera/SKILL.md) 和 [cc8-announce](../skills/cc8-announce/SKILL.md)。复制到当前 Codex 用户的 skills 目录，按实际运行目录设置本机路径；不要把本机凭证、配对或签名复制进技能。保持正常自动发现，不加入定时或无人值守触发。

自动回归覆盖私有 IPC / 文件权限、客户端断开、错误请求关联 / 哈希 / 大包、旧代拒绝、取消后不返回图片、无麦克风拍照、已有麦克风保持及新旧相机任务清理隔离。实机记录见 [VALIDATION.md](VALIDATION.md)。
