`individual_replay` 分别记录 `primary`、`alternate`、`raw` 的 `not_run`、`unavailable` 或本地 `keyword_hit` 布尔值。只有自身完整且形状匹配的输入才参与；另一条输入不匹配不再抹掉这个结果。三路全部匹配时同时保留原 `fresh_replay` 汇总，只做一轮分路复核，不为汇总重复解码。离线检查拒绝缺帧输入冒充完整匹配，或分路结果与汇总矛盾。没有云识别、识别正文或音频导出。

中文 `live_decoder.primary_samples_before` 是第一帧解码前在同一 native 锁内读取的实际流位置；它不把对照用的 alternate／raw 叫作运行中的中文检测流。缺失位置保持未知，布尔值／负数／越界位置无效。旧英文双流位置和播报门控计数保持原规则。
