# 光环界面、任务与提醒（0.8.5）

Android 0.8.5 / versionCode 30，Mac 后台 0.11.0。设计依据是用户确认的[方案一修订稿](design/bumblebee-orbit-v1.png)。

## 主屏

左侧保留 G1 大黄蜂头像及完整旋转光环；状态文字位于独立粒子声波下方，不进入光环。右侧为用户指令、随真实播放进度高亮的字幕、任务回执和下一条提醒。底部可切换唤醒 / 自由对话，进入看一看、任务、语音启停和设置。

字幕高亮采用 MiniMax 时间戳与 AudioTrack 播放头。进度时间来自实际播放帧；音频尚在流入时仅显示已播时长，不预设总时长。音频暂停时进度和嘴型一同暂停。相机继续使用明确前台动作和 5 秒可见取景。

设置包含媒体音量、助理大脑、提醒、来源、最近 Dot 完整结果、连接 / 桌面入口和隐私说明。没有把噪声阈值改成未经设备验证的自动调节。

## 真实任务回执

任务来自实际文字或语音请求。检索、命令、文件修改与工具调用依据 Codex 的 item/started、item/completed 事件更新，不显示虚构步骤或百分比。Dot 的成功 turn/completed 和最终结果关闭任务；用户随后停止朗读不会把已经完成的工作改为取消。

可以查看最近最多 12 条任务及结果摘录，服务重启后清空。文本只保存在内存，提醒另行持久化。正在执行的任务可以取消等待；这不会撤销已经完成的文件修改或外部动作。

任务 → 文字指令可在麦克风关闭时向同一个 Dot 大脑交办工作，接收语音和字幕结果。文字指令不打开麦克风或摄像头；后台、断线、切换通道和取消仍会使旧结果失效。

## 最终回答流式播报

仅当 item/started 明确标注 agentMessage.phase=final_answer 时，客户端才消费该 item 的 item/agentMessage/delta，分句开始合成与播放。commentary、推理、其它轮次和未知阶段不会流入语音。旧服务未提供阶段信息时保留完成后播报路径。

完成事件的全文为权威结果，流式已播内容不重复播放。最终全文与已接收增量不一致时明确失败。文本增量队列在播放阻塞期间合并同一 item 的连续增量，限制单条结果和队列大小，防止 TTS 播放导致事件积压断线。

## 提醒

支持一次、每天、工作日、每周提醒；通过语音或界面新增、查看、修改、取消、稍后 10 分钟。Dot 使用真实 cc8_reminder 工具，修改 / 取消先查询实际 ID。日期以当次北京时间和明确时区解释。

提醒保存到本机忽略目录 device-access/private/voice-runtime/reminders.json，目录 0700、文件 0600，临时文件 fsync 后原子替换。写入失败不显示成功，内存回滚；损坏的存储不会被静默覆盖。最多 32 条待提醒事项。

到时仅在 Mac 服务运行、CC8 助手前台且认证连接有效时播放。不打开麦克风、相机或后台拉起设备，不打断当前对话、播报和看图；忙碌或离线时延后。实际播放完成后才标记送达；失败 / 被打断后至少间隔 5 分钟再尝试。重复提醒跳过已经错过的周期，不连续补播所有过期记录。

这些是本程序提醒，不是原厂系统闹钟；Mac 休眠、关机、服务未启动或 CC8 不在前台时不能保证准点播报。暂未提供安静时段、手机通知和系统日历同步。

## 私有桌面入口

现有 owner-only Unix socket 增加 text_request、workspace_status、reminder_action。请求仍受本机目录 / socket 权限保护，不能作为公共网络 API 使用；不改变设备连接或采集权限。已有播报、拍照入口保持兼容。

## 本轮验收

后台单元测试、Android assembleRelease / lintRelease 通过。真实 CC8 验证了同签名更新、麦克风关闭时的 Dot 只读任务及任务回执、Dot 创建 / 查询 / 取消提醒、定时播报完成回执；临时待提醒均已取消或完成。界面比对记录见仓库根目录 design-qa.md。

新 UI 的真实口头远场 / 噪声测试、USB 物理拔插后的完整任务链、长时间运行和 15 分钟待机验收仍需单独完成。

## 方案一的还原与字号

0.8.1 按确认图的 1280×800 坐标重新排版，恢复短弧刻度光环、头像比例、右侧任务 / 提醒分区和底部胶囊按钮。字体调整遵循用户追加要求：播报正文保留 42sp，其他文字放大；按钮 22sp，用户文字和任务标题 24sp，提醒 23sp，状态 20sp，弹窗正文 22sp。图标来自 Google Material 与 Phosphor 的正式资源，许可随 APK 打包。图中示例任务和提醒不写入真实用户数据。

## 字幕与进度条隔离（0.8.2）

字幕容器显式裁剪基础文字和卡拉 OK 高亮，禁止越过右侧字幕区绘制。播放头进入新行时，若该行不能完整显示，则直接滚动到完整行；保留 42sp 正文、原字幕区域和进度条位置。97 字真实播报覆盖 7 行及末行，当前朗读行全部可见，字幕容器与进度条无交集。

## 光环时钟与播报光轨（0.8.3）

用户追加设计要求：头像光环改为抽象时钟，保留方案一其余排版。60格刻度固定在12点起位，琥珀色短弧指示小时，青色短弧指示分钟，外圈秒点和短尾随实际秒数移动；头像下方、光环内显示24小时制 HH:mm。使用 CC8 系统当前时间和时区，每秒刷新读数，每分钟更新无障碍描述；秒点平滑移动。时钟不依赖联网请求，不增加后台定时器，待机亮屏后重新读取当前时间。

播报进度改为32段青色光轨、切角边框、标尺与菱形游标。亮起长度及游标沿用实际字幕播放进度，不制造向前动画；时间读数仍来自真实播放帧。光轨区域 y390/h24，字幕仍止于 y382，明确隔开，正文保持42sp。

## 长短黄线时钟（0.8.4，替代上一版时分短弧与数字读数）

按用户最新要求，时针、分针统一为加粗黄色径向线段：短且较粗的是小时，较长的是分钟，均只占光环环带、不穿过头像。时针随分钟连续偏移，分针随秒数连续偏移。移除可见数字时钟和底部数字底板，保留60格刻度、外圈平滑跑秒点与短拖尾。系统时间、时区、无障碍时间描述保持原路径；分段播报光轨不变。

## 更醒目的真实跑秒（0.8.5）

外圈秒点增大并加入白色亮芯；秒点前端弧线加粗到6个绘图单位，后接4、3单位两段逐渐变暗的拖尾，总长36度。保留黄色长短时分线，不恢复数字时间。秒点位置直接读取系统墙上时间：00秒位于12点、15秒3点、30秒6点、45秒9点，顺时针回到12点即下一分钟；不会在启动或播报开始时重置。播报进度条三款新设计等待用户选择，设备仍保留0.8.3的分段光轨。
