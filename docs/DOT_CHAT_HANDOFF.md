# P1-01：显式选择桌面聊天，摘要接续

候选后台 0.14.0 / 助手 APK 0.8.9 code 34 / 协议 2。独立分支基于 P0 待测基线 [p0-validation-base-20261102.1](https://github.com/batipang/CC8/tree/p0-validation-base-20261102.1)（d359552），未替换后台、安装 APK、开启采集或向任何既有桌面聊天追加消息。

## 本机可行性结论

2026-11-02，本机 CLI 为 codex-cli 0.166.0。实际初始化独立 app-server，使用 thread/list 的 useStateDbOnly 仅查元数据；返回的十条记录中，包含桌面工具所列五条聊天的同一 ID。没有为这次探测读取正文、启动模型回合或恢复聊天。

本机 app-server proxy 无法连接共享服务，daemon version 也未找到可用管理实例；独立进程对列表返回 notLoaded，不能由此判断桌面是否正在执行。故**本版不直接 thread/resume / turn/start 到原桌面聊天**。这是本机验证的边界，不推断所有安装或版本均不支持。官方 [App Server 文档](https://learn.chatgpt.com/docs/app-server) 区分元数据读取、分页历史和恢复后追加回合；这些接口的存在不证明独立客户端具备当前桌面全部工具或安全接管能力。

采用 TODO 允许的有来源摘要交接。模型、推理、技能和工具仍来自现有 owner CLI 配置；CC8 控制、Mac 打开、提醒仍为该独立语音客户端的动态工具。桌面宿主专有工具与会话同步未经验证，不声称全面一致。需要审批仍按原策略拒绝并说明桌面处理方式，不自动批准。

## 操作入口

1. 大黄蜂“设置 → Dot 聊天接续”。状态明确显示独立语音或摘要来源；不会开启麦克风。
2. 点击“选择聊天”，每页最多十条标题与项目名称，支持下一页；列表不展示 preview、完整路径、消息或历史内容。只有当前列表中五分钟内的选择可用，最多缓存一百个选择和对应游标。
3. 选择标题，再确认“摘要接续”。确认后只读该聊天最近三个回合中的已完成纯文字问答：每条最多一千字符，总计最多六条。跳过未完成回合、没有明确 final_answer 的回答、推理、工具输出、图像和文件；可能截断，不能称完整历史。
4. 后续新请求在**独立 Dot 语音上下文**处理。历史摘录按 JSON 引用数据输入，不授权重新执行旧请求；新上下文只注入一次，失败重建时再注入。换来源或“独立语音”会重置旧语音上下文，不混用。只有所选聊天的本地目录仍存在且没有远端环境时，才用于新独立会话；不复制原终端/运行任务或覆盖权限。失效/远端项目标明未接入，提示明确目标，不能把 CC8 仓库冒充原项目。
5. 本次任务结果显示摘要来源和“未追加原桌面聊天”。在“最近 Dot 完整结果”可手动复制，回到目标桌面聊天粘贴；不自动发送桌面消息。

## 资源与取消

列表/选定历史使用独立短命 RPC 客户端，仅调用 thread/list、thread/read(includeTurns=false)、thread/turns/list。所有分支关闭自有客户端，不终止桌面服务。初始化与各查询有超时，单个后台工作槽；主 packet/capture reader 不等待这些查询。

修改来源要求音频、校准、识别、回答、取景和队列均空闲；检查与提交在会话 owner 事务中完成。用户取消、Home/断连或代次改变使未提交的结果失效；读取步骤之间也核对取消，已在传输中的只读查询有界结束。请求失败保留旧选择，不自动尝试其他聊天或模型，不重复工具动作。取消在提交后到达时不撤销已确认状态，须刷新查看。

标题、聊天 ID、摘录及选择均只在内存，不写配置、health、status、日志或 Git。当前新问题仍沿用已有模型服务；摘录只在之后主动交办请求时随上下文使用，不在选择时生成答案。重启后回到独立会话。

新 Android 入口使用随机请求 ID 过滤旧回包，后台返回握手状态不弹窗。退出前台取消等待、清理进度对话框及定时器；未获取正文的元数据列表也不自动授权选定某条。

## 验证与未完成项

新增十六项离线方法覆盖五个合成候选、分页/过期/非候选 ID、已完成文本过滤、截断、客户端关闭、取消后不再读下一步历史、切换/清除/失败保留、并发失效、输出不含提供方异常、health/status 不落盘上下文，以及迟到 interrupt 绑定原 thread。原 Dot 最终回答/工具权限/审批/取消回归保留。

本机真实验证只证明元数据可发现（同五个 ID），**不是五个既有聊天的选择→语音→桌面结果端到端验收**。本机最终全套 installer 22、host 473（4 private-audio skip）、tooling 51、Java 15 checks，固定质量/strict 七模块通过。Android 已实际原 JKS 引用 assembleRelease / lintRelease；设备端交互和真人语音尚未测。首次编译检出一个旧清空回调缺少新来源参数，补齐后通过，没有关闭 lint 或弱化类型签名。

共享原聊天、桌面自动回填和桌面专有工具能力仍开放；P1-01 复选框保持未关闭。P0 的固定真人/物理切换/待机验收也不因本功能通过离线测试而完成。后续按 [TODO](TODO.md) 和 [VALIDATION](VALIDATION.md) 保留证据。
