# CC8 拍照并显示到当前聊天

只在用户当前明确要求拍照，或明确要求开发并测试该拍照入口时执行。一次请求、一张照片：CC8 前台显示 5 秒实时预览和倒计时，随后拍摄、关闭镜头，将 JPEG 返回到当前 Mac。保持用户现有麦克风开关状态。

运行目录：使用已经连接 CC8 的工作目录，定位 `cc8-assistant/host/camera.py`；所有相对路径从项目根目录解析。不要在另一个克隆中启动重复后台。先读该项目的 AGENTS.md 及 cc8-assistant/AGENTS.md（如存在）。

## 准备

通过 `device-access/private/voice-runtime/announce.sock`（0600 Unix socket）发出一行 JSON `{"operation":"device_control","arguments":{"action":"status"}}`，读取实时回执的 `ok`、`foreground`、`transport`、`microphone_active`。不要仅凭缓存 status.json 或文件存在认定在线。

服务未启动时运行一次 `python3 cc8-assistant/host/launch.py --no-open`。设备已在前台时直接拍照，不重复拉起；确需通过 USB 打开界面时用 `launch.py --no-auto-voice`。不要使用默认启动或桌面按钮作为“仅拍照”的准备方式，它们会按用户设置自动开麦。仅 Wi-Fi 且设备不在前台时，当前不能远程静默拉起，应说明需要用户打开助手或接 USB。缺 CAMERA 权限时，由用户在设备前台点「看一看」授权，再请求拍照；不通过系统命令强行授权。等待校准或已有看图任务结束。

## 拍摄与显示

执行一次：

```sh
python3 cc8-assistant/host/camera.py
```

程序通常在预览结束后返回 JSON。`status=completed` 的 `path` 是已校验、当前新拍摄照片的绝对路径；文件位于忽略的 `device-access/private/photos/`，目录 0700、JPEG 0600。工具仍在运行时继续等待该进程，不重复提交。

成功后用图片查看工具检查这份 JPEG，再用 Markdown 图片语法将**同一个绝对路径**内嵌到当前回复，例如 `![CC8 本次拍摄](/绝对路径/照片.jpg)`。必须显示图片，不能只给文字说明或下载链接。用户要求识图时，基于这张实际图片回答，区分观察和推测；仅要求拍照时简短确认并展示即可。

失败、超时、取消、断线或校验错误时，不使用上次图片代替，也不自动重拍；说明本轮未确认取得照片，只有用户要求重试才再次执行。客户端断开会取消尚未完成的拍摄；拍摄后已提交的内容不能因后续取消而撤回。

照片为用户要求在聊天中展示而保存，不写日志、不进 Git、不创建公开链接、不自动转发到其他服务或联系人。不为此创建定时任务、后台监控或自动清理；保留本地文件以维持聊天图片可用，用户要求删除时再处理。原有语音／按钮看图分析仍只在内存中传图，不因安装本技能自动保存照片。
